framework used by orgs to improve processes, increase efficiency, and reduce errors (kinda like [[Six Sigma]] if you think about it). 
CMMI answers: how mature and reliable are processes in our company
if low: BAD, CHAOTIC, INCONSISTENT
if high: structured, optimized, consistent 😄👍

## LEVELS OF CMMI
first, INITIAL
no structure, everything is reactive, chaotic, low maturity, success is luck

secondly, MANAGED
basic processes exist, can repeat some success, still kinda chaotic

thirdly, DEFINED
processes are [[standardization|standardized]] across the company.

fourthly, QUANTITATIVELY MANAGED
uses data and metrics to control processes

fifthly, OPTIMIZING
continuously improving - so like [[Kaizen]] - always refining systems
