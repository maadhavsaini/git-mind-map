A [[Project Management]] tool for managing time - break a project into activities, show how they depend on each other. Used in [[Planning]]
Basically, each task is a bubble, and lines are drawn between bubbles when they are connected, and when one task happens after another.

Groq Says: "PERT stands for Program Evaluation and Review Technique. It's a method used to plan, organize, and coordinate tasks in a project. PERT is a graphical representation of a project's schedule, showing the relationships between tasks and the time required to complete each one."
![[Pasted image 20260412090824.png]]



PERT is one of several [[Critical Path Management]] tools, and is thus closely related to 
[[Critical Path]]. In fact, this is how you manage the [[Critical Path]].
